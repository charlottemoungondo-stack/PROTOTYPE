# Prototype Liane

Prototype cliquable de l'application de rencontre **Liane** (application où chaque membre vérifie son identité et sa présence réelle).

👉 **Ouvrir le prototype :** https://charlottemoungondo-stack.github.io/PROTOTYPE/

Toutes les personnes, photos (illustrations) et paiements sont **fictifs**. Rien n'est enregistré : recharger la page remet tout à zéro.
Le code de l'application (serveur, tests) se trouve dans un dépôt séparé et privé.
